# 小键盘 17 颗 RGB 实际串联顺序

来自用户已上传的立创 EDA Pro 文件：
`ProDoc_键盘87_小键盘_2026-11-03(1).epro`。
用 `PCB/0f93978a359ba176302696e1f0a5a380.epcb` 的 `PAD_NET` 数据追踪 **每个组合按键器件 L2(DIN) / L4(DOUT)**，从网络 `DIN` 开始逐个跟随至网络 `DOUT`，而非按照键盘行列顺序猜测。

| 相对 LED 序号 | 物理位置/标签 | 网络路径 |
|---:|---|---|
| 0 | Num Lock | DIN → U1 L4 |
| 1 | / | U1 L4 → U44 L4 |
| 2 | * | U44 L4 → U71 L4 |
| 3 | − | U71 L4 → DA0 |
| 4 | 7 | DA0 → U2 L4 |
| 5 | 8 | U2 L4 → U51 L4 |
| 6 | 9 | U51 L4 → U73 L4 |
| 7 | + | U73 L4 → DA1 |
| 8 | 4 | DA1 → U56 L4 |
| 9 | 5 | U56 L4 → U57 L4 |
| 10 | 6 | U57 L4 → U68 L2 |
| 11 | Enter | U68 L2 → DA2 |
| 12 | 1 | DA2 → U62 L4 |
| 13 | 2 | U62 L4 → U63 L4 |
| 14 | 3 | U63 L4 → U66 L4 |
| 15 | . | U66 L4 → U3 L2 |
| 16 | U3 额外底排灯（数字 0 位置） | U3 L2 → DOUT |

**合计：17 颗 LED。** U3 的 RGB 已接入灯链；其开关需要按下文说明额外接入 MCP 0x21 空闲矩阵位置。

## 正式纳入空间彩虹（实验固件 keyflux_numpad_spatial_zero）

- LED 总数仍为 **100**；已经拥有实际空间坐标的灯扩大为 **88**（主键盘 0～70，小键盘 71～87）。
- 依照实际 PCB 的 LED DIN/DOUT 顺序将小键盘相对 0～16 对应绝对编号 **71～87**，包括独立 U3 的 0 键 RGB（编号 87）。
- 空间彩虹模式 3 横向统一按 **X=0～44** 的坐标渐变、模式 4 纵向统一按 **Y=0～4** 渐变；不会因为 PCB 的串联顺序打乱颜色。
- 88～99 灯仍保持此前的按链序动画行为，没有假装这些尚未确认的灯已有空间坐标。
- 此固件假定你先前实机测试成功的小键盘起始号是 **71**。Qt 的“起始 LED 编号”仍能调整逐灯测试，但调整 GUI 参数**不会自动修改 MCU 固件里的空间灯号映射**。

## 小键盘物理 0 键（U3）输入接法

**U3 的 KEY1/KEY2 在原 EDA PCB 里是未接入按键矩阵的独立网络**，RGB 可亮 ≠ 可以按键输入。你目前的 MCP 0x27 矩阵已经占满 4×4 共 16 个位置。为避免增设 MCP23008 或占用 STM32 新 GPIO，本测试版将 USB HID **Keypad 0 (0x62)** 分配到主键盘右侧 MCP **0x21 的空闲 R0/C0**：

| 小键盘 U3 开关焊盘 | 接到主键盘 MCP 0x21 矩阵 | 说明 |
|---|---|---|
| `KEY1` / `K1` | `C0` / `GP7` | 列线，扫描时拉低 |
| `KEY2` / `K2` | `R0` / `GP3` | 行线，输入上拉 |

须保证 U3 按键的原配二极管方向符合现有其余按键的 K1→列、K2→行拓扑；接线前断电，仔细确认器件丝印及实际网络，且不要接到 LED 的 L2/L4。**在接好两根飞线之前，按下 U3 不会触发键值，这是硬件限制，不是固件编译失败**。

固件映射为 `{0x21U, 0U, 0U, HID_KEY_KP_0, 0U, 87U}`，与小键盘 LED87 对应。因此接好线之后，按下 0 才会发送 USB Keypad 0，并可触发 LED87 按下高亮。

## 与原有 100 颗灯的关系

STM32 固件当前 `LED6028_COUNT=100`，主键盘空间坐标的灯索引是 `0..70`。如果小键盘的 `DIN` **实物接在主键盘第 71 颗的 DOUT 后**，那么相对小键盘 LED `0..16` 对应绝对灯号 `71..87`。

但 **PCB 工程仅能证明小键盘自身的链路顺序，无法证明它与主键盘实际插线后的绝对起始号**。所以 KeyFlux GUI 提供可调整的起始序号（默认 71），支持单灯点击与上/下一颗测试，不需要刷机即可核对序号。

若小键盘接在物理灯号 99 之后、独立控制 GPIO 上，或未接入目前 PB6 控制的 LED 数据链，则现有 `0..99` 的固件单灯命令不能直接点亮，需要针对实际连接方案扩展固件。

## KeyFlux 使用

1. 切换 MultiPad，连接键盘 USB。
2. 在「数字小键盘 RGB · 实物单灯测试」中设置起始编号（默认 71）。
3. 点击 **Num**，应只亮第一颗灯；继续点击 `/`、`*`、`-`，直到最后的 **0**。
4. 如果亮灯整体偏移，调整起始编号并继续验证。KeyFlux 会在 PC 上保存起始号。
5. 完成后点击「停止测试」恢复原灯效。

此测试只使用固件已有的 `0x07` 单灯命令；不会改键盘 RGB 存储设置，也不会主动写 STM32 Flash。
