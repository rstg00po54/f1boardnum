要求：新版 Chrome 或 Edge、USB 数据线、支持 WebHID 的固件；本机使用 http://localhost:8080/web/ 访问，或通过 HTTPS 部署。此页面不上传任何键盘日志到服务器，所有通信都在浏览器与 USB 设备之间进行。使用的是自定义 WebHID 协议，不是 VIA 固件协议。
